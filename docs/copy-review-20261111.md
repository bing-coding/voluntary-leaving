## 验收路径

本轮本地验证：7 个测试文件中的 57 条用例全部通过，`git diff --check` 通过；桌面 1280×720 与手机 390×844 登录页已检查。实际点击验证了新身份和日期、家长节点证据 01、申请书证据 02、谈话原文证据 03，以及退宿与续费双记录取得证据 05。浏览器控制台未见警告或错误。完整多结局仍需人工验收。

1. 登录页核对校园背景和学号 2023060713；登录后查看页头“2023级”、日期 2026-06-25、“学籍变动”及 XJBD 编号，核对家长确认 09:17、周三课“已结束”。
2. 材料归档 → 谈话记录 → 点击查看原文；确认弹窗打开、证据 03 入夹，关闭后可再次查看。
3. 材料归档 → 宿舍退宿；分别点击退宿申请和宽带续费记录，确认取得证据 05、宿舍系统解锁、电子回执出现，且没有旧维修照片。
4. 学生事务 → 查看谈话材料历史版本；确认新摘要、撤回标记、账号、所属单位及证据 16。
5. 心理转介单 → 转介材料来源；确认复学前出现新权限提示，恢复学籍后仍可查看完整来源并取得证据 04。
