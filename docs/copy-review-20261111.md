宿舍宽带回执是根据编辑“缴纳长期费用以体现长期居住意愿”的建议补成的游戏内容，需在测试中验收。它支持质疑退宿意愿，不能单凭续费记录断言申请必为伪造，因此证据结论采用“相互矛盾，需核验来源”。证据编号及通关门槛不变。旧存档中的 `dorm-repair` 检查键继续有效，避免已检查的记录丢失。

## 已知设定问题

编辑原稿要求“2027级”，与游戏当前 2026 年时间线及登录页既有学号不一致。项目方在本轮明确要求按编辑原稿执行，因此这里只修改指定身份栏，没有擅自把整个剧情年份、学号或图片改为另一套年份。该设定问题保留供正式上线前统一校对。

## 验收路径

1. 登录，查看页头“2027级”。
2. 材料归档 → 谈话记录 → 点击查看原文；确认弹窗打开、证据 03 入夹，关闭后可再次查看。
3. 材料归档 → 宿舍退宿；分别点击退宿申请和宽带续费记录，确认取得证据 05、宿舍系统解锁、电子回执出现，且没有旧维修照片。
4. 学生事务 → 查看谈话材料历史版本；确认新摘要、撤回标记、账号、所属单位及证据 16。
5. 心理转介单 → 转介材料来源；确认复学前出现新权限提示，恢复学籍后仍可查看完整来源并取得证据 04。
6. 桌面和手机各检查一次文字换行、弹窗关闭与证据侧栏。

确认效果后，再将本分支合入 `main` 并单独部署正式 Pages 项目。原正式项目采用直接上传方式，合入 GitHub 本身不会自动更新正式游戏。
